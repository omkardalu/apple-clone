# Apple Website Clone

A clean, responsive HTML and CSS recreation of Apple's product showcase website. This project demonstrates modern web design principles with a minimalist aesthetic and intuitive product navigation.

[Live here]("https://omkardalu.github.io/apple-clone/")
## Overview

This is a **static website** built with vanilla HTML5 and CSS3, featuring Apple's signature design language, color scheme, and product layout. No frameworks, build tools, or JavaScript required.

## Features

- **Fixed Navigation Header** - Sticky navigation bar with Apple logo and navigation links
- **Product Showcase** - Beautifully designed product cards highlighting:
  - Vision Pro
  - Mac and MacBook Air
  - iPhone
  - iPad Pro
  - Apple Watch
  - Apple Intelligence
  - Apple Card
  - Trade-In Program
- **Responsive Design** - Optimized layouts for desktop, tablet, and mobile devices
- **Hero Sections** - High-impact product pages with call-to-action buttons
- **Comprehensive Footer** - Multi-column footer with navigation and legal information
